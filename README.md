## 🏠 HomeTogether

> **빈 방을 가진 어르신과 집이 필요한 청년을 연결하는 세대공유형 주거 서비스**

### 문제

고령 1인 가구는 자녀가 떠난 넓은 집에 혼자 남아 빈 방과 고립을 안고 있고, 청년은 감당하기 힘든 월세 때문에 좁고 열악한 집을 찾습니다. 두 세대의 수요는 정확히 서로의 해답인데, 이를 안전하게 연결해주는 통로가 없었습니다.

### 해결 방식

홈투게더는 어르신의 빈 방을 청년에게 중개하고, 단순 중개에서 끝나지 않도록 **입주 전 검증 → 매칭 → 입주 후 관리**까지 하나의 플랫폼에서 관리합니다.

| 단계 | 내용 |
|---|---|
| 1️⃣ **방 등록** | 어르신이 빈 방을 등록, 실사를 통해 주거 환경 검증 |
| 2️⃣ **매칭** | 생활 패턴과 성향을 고려해 어르신–청년을 연결 |
| 3️⃣ **입주** | 계약 및 체크인 프로세스 지원 |
| 4️⃣ **사후 관리** | 입주 후에도 생활 규칙 정리와 갈등 조정을 지원해 관계가 유지되도록 관리 |

**양쪽이 얻는 것**
- 👵 **어르신** — 안정적인 임대 수입 + 함께 사는 사람이 생기는 생활 안전망
- 🧑 **청년** — 시세보다 낮은 주거비로 안전한 주거 확보
